# 🐍 스네이크 게임

HTML, CSS, JavaScript만으로 만든 브라우저 스네이크 게임입니다. 별도의 설치나 빌드 없이 바로 실행할 수 있습니다.

## 실행 방법

1. 이 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/bridgeaiedu-jsu/snake-game.git
   ```

2. `index.html`을 브라우저에서 엽니다. (VS Code의 Live Server를 써도 됩니다.)
3. `게임 시작` 버튼을 누르고 방향키(↑ ↓ ← →)로 뱀을 조종합니다.

## 게임 규칙

- 400x400 캔버스를 20x20 격자로 나눈 판에서 진행합니다.
- 먹이를 먹으면 뱀이 한 칸 길어지고 **+10점**을 얻습니다.
- 벽이나 자기 몸에 부딪히면 게임 오버입니다.
- 게임 오버 후 `다시 시작` 버튼으로 다시 도전할 수 있습니다.

## 기능

| 기능 | 설명 |
| --- | --- |
| 최고 점수 | 브라우저 LocalStorage에 저장되어 새로고침해도 유지됩니다. |
| 난이도 선택 | 쉬움(200ms), 보통(150ms, 기본값), 어려움(100ms), 매우 어려움(50ms). 값은 뱀이 한 칸 움직이는 간격입니다. 게임 중에는 바꿀 수 없습니다. |
| 일시정지 | 버튼으로 일시정지/재개를 전환하며, 버튼 글자도 `일시정지` ↔ `재개`로 바뀝니다. |
| 레벨 시스템 | 50점마다 레벨이 오르고, 레벨업할 때마다 이동 간격이 10ms씩 줄어듭니다. (최소 20ms) |
| 효과음 | 시작, 먹이, 레벨업, 게임 오버 효과음이 나며 `소리` 버튼으로 켜고 끌 수 있습니다. 음원 파일 없이 Web Audio API로 직접 만든 소리입니다. |

## 파일 구조

```
.
├── index.html   # 화면 구성
├── style.css    # 스타일
└── main.js      # 게임 로직, 그래픽, 효과음
```

## 사용 기술

- HTML5 Canvas
- Vanilla JavaScript (외부 라이브러리 없음)
- Web Audio API
- LocalStorage
